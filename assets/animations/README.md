# Otya motion assets

OTYA has one canonical logo with two states, not two different logos.

## Static / normal state

- Use the normal `OtyaMark` everywhere for branding, navigation, launcher surfaces, messages, splash/static artwork and ordinary UI.
- The O itself is still.
- The three resting balls stay in their approved resting position.
- The horizontal wordmark is the O mark followed by lowercase `tya`.

## AI thinking state

- Use `OtyaThinkingMark` only while Ask OTYA is actively processing.
- The large O never rotates or spins.
- Only the blue, red and yellow balls move.
- The balls travel continuously around the full curved inner route of the O.
- The front ribbon is painted over the balls for part of the route so they appear to pass behind the overlap and reappear.
- When thinking ends, animation stops and the normal static mark returns.
- Reduced-motion accessibility settings stop the motion and show the static state.

## Web

`otya_ai_thinking.svg` contains the same thinking motion for website use. Keep `otya_mark.svg` as the static/default logo.
